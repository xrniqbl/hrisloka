## FASE 1 — Keamanan (prioritas tertinggi)

### 1.1 Secret leak: VAPID private key di git
- `vapid-keys.json` (root) ter-track di git, berisi private key asli. `.gitignore` sudah mencantumkannya tapi tidak berlaku untuk file yang sudah ter-track.
- Aksi: `git rm --cached vapid-keys.json`, verifikasi `.gitignore` mencakupnya, dokumentasikan instruksi ROTASI kunci di `docs/` (rotasi harus dilakukan manual via `npx web-push generate-vapid-keys` + update env VAPID_* di Vercel/VPS).
- Catat risiko: key sudah masuk history git → rotasi wajib, bukan opsional.

### 1.2 `api/attendance/clock-in.js` tidak memverifikasi JWT (CRITICAL)
- Saat ini hanya cek header `Authorization` ada → siapa pun dengan string acak bisa insert baris absensi via service-role key (bypass RLS).
- Aksi: verifikasi JWT seperti pola fail-closed di `api/send-email.js` / `api/ai-review.js` (GET `{SUPABASE_URL}/auth/v1/user` dengan bearer), lalu:
  - Ambil `employee_id` dari session, TOLAK jika `req.body.employee_id` ≠ employee milik session (cegah absensi atas nama orang lain).
  - Ambil `company_id` dari record employee, tulis eksplisit ke row (jangan percaya body client).
  - Sanitasi field numerik/boolean yang masuk (sebagian sudah ada).

### 1.3 Schema hilang: `billing_info` + `onboarding.company_id`
- `billing_info` dipakai `src/services/billingService.js` tapi tidak ada CREATE TABLE di repo (RLS-nya pun conditional "if exists").
- `onboarding` dipakai `src/pages/OnboardingChecklist.jsx` dengan kolom `company_id` yang tidak ada di definisi `migration_batch2.sql`.
- Aksi: buat `supabase/migrations/fix_audit_missing_schema.sql` — CREATE TABLE IF NOT EXISTS `billing_info` (company_id, contact/billing fields yang dipakai service, RLS tenant) + `ALTER TABLE onboarding ADD COLUMN IF NOT EXISTS company_id uuid` (+ index + RLS policy tenant).

### 1.4 CORS Edge Functions: `*` → allowlist
- 3 edge functions (`create-payment`, `midtrans-webhook`, `activate-free-subscription`) pakai `Access-Control-Allow-Origin: *`. Samakan dengan pola `api/_shared/cors.js` (allowlist hrisloka.id/.com + localhost). Webhook Midtrans tidak pakai CORS (server-to-server), cukup 2 fungsi lainnya.

### 1.5 Konsolidasi script SQL produksi
- Banyak runbook RLS yang harus dijalankan manual di prod (GO_LIVE_RLS_RUNBOOK, fix_employees_rls_super_admin_leak, harden_tenant_rls_bcd_2026, harden_notifications_company_settings_rls).
- Aksi: buat `scripts/RUN_AFTER_AUDIT.sql` — satu file gabungan idempoten (urut: helper functions → RLS hardening → fix missing schema) + `docs/POST_AUDIT_CHECKLIST.md` berisi query verifikasi (0-row leak test, tabel billing_info ada, onboarding.company_id ada) dan langkah rotasi VAPID.

## FASE 2 — Bug fix

### 2.1 Infinite loading saat fetch gagal
- `src/pages/Employees.jsx:41-47` — `fetchEmployees` tanpa try/catch → skeleton infinite jika query reject. Tambah try/catch/finally + error state + tombol retry.
- `src/pages/LeaveManagement.jsx:34-44` — pola sama pada `fetchData` (Promise.all). Perbaikan identik.
- Cek cepat halaman lain dengan pola serupa (audit git log menyebut beberapa sudah pernah diperbaiki; fokus pada 2 file ini dulu).

### 2.2 localStorage tanpa try/catch di boot path
- `src/main.jsx:18-38` — theme/locale dibaca/ditulis di level modul tanpa guard → app bisa blank di Safari private mode / storage diblokir.
- Aksi: gunakan wrapper safe yang sudah ada di `src/lib/safePath.js` (safeGet/safeSet) di main.jsx, `src/App.jsx:236-249` (grace flag), `src/components/ProfileDrawer.jsx`, `src/components/Sidebar.jsx` (viewAs), `src/layouts/EmployeeLayout.jsx`, `src/layouts/FounderLayout.jsx`.

### 2.3 Ganti window.confirm/prompt dengan modal
- `src/pages/founder/FounderSubscribers.jsx` (prompt alasan cancel, prompt extend hari, confirm cancel subscription — aksi destruktif tanpa undo).
- `src/pages/employee/EmpSubmissions.jsx:262` (confirm batalkan pengajuan).
- Aksi: pakai komponen Dialog/modal yang sudah ada di proyek (pola astryx dialog) — konfirmasi eksplisit + input alasan, bukan prompt browser.

### 2.4 Silent catch yang menyembunyikan kegagalan
- `src/services/companyService.js` — 3 rantai `.catch(() => {})` pada promise query → minimal tambahkan `console.warn` dengan konteks, agar kegagalan teramati Sentry.

### 2.5 Bug kosmetik kecil
- `src/pages/BranchManagement.jsx` `LOCATION_TYPES` — `icon: '?'` rusak (emoji ter-strip) → perbaiki/normalisasi.
